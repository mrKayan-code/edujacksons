# CLAUDE.md — конвенции проекта EduJacksons

## Что это за проект
Платформа репетитора по программированию + подготовка к ЕГЭ. Бэк на Java (карьерная цель
владельца — Java-разработчик + опыт микросервисов). Полное ТЗ — в `task.md`.

## Как работаем
- **`task.md` — источник правды.** Сначала уточняем/правим ТЗ, потом пишем код.
- **Роли ИИ.** Я — главный разработчик: пишу код, тесты, миграции, ADR. Расширенную документацию
  (детальные Javadoc, README модулей, walkthrough, объяснение кода пользователю) пишет отдельный
  doc-агент рядом — этот шаг не мой, не дублирую его. Но краткие пояснения к функциям (что делают)
  и описания архитектурных решений оставляю сам.
- **Одна сессия = одна фаза** роадмапа (`task.md` §7). В начале сессии свериться с чеклистом фазы,
  в конце — отметить сделанное (`[ ]` → `[x]`).
- Крупные темы — в `docs/` (`architecture.md`, `db-schema.md`, `api-contracts.md`,
  `ege-integration.md`). Читать точечно, не всё сразу.
- Архитектурные решения фиксировать в `docs/adr/` новым файлом `NNNN-<slug>.md`.

## Стек (кратко; детали и обоснования — `docs/adr/0001-tech-stack.md`)
- Java 21, Spring Boot 3.x, Gradle (Kotlin DSL)
- PostgreSQL + Flyway, Redis, Kafka
- Spring Security + JWT, роли TEACHER/STUDENT
- Judge0 за интерфейсом `CodeExecutor`
- Frontend: Next.js + TypeScript (API-first)

## Кодстайл (детализируем при первом коде)
- Модульный монолит: границы модулей строгие, между модулями — только публичные интерфейсы/события.
- Пакеты внутри модуля: `api / domain / repository / service / config`.
- Миграции только через Flyway. UUID-ключи. `created_at`/`updated_at` везде.
- Тесты: JUnit 5 + Testcontainers (реальные PostgreSQL/Kafka).

## Владелец
- Идёт на Java-разработчика, хочет реальный опыт микросервисов и промышленного стека.
- Не обязан разбираться в настройке ассистента/харнеса — это на мне.
